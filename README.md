# Derivatives Pricing & Hedging in Python

Python projects demonstrating practical derivatives valuation, Greeks, Monte Carlo simulation and dynamic hedging.

## Projects

### `option_pricer.py`

Black-Scholes pricer for European call and put options, including Delta, Gamma, Vega, Volga, Rho and Theta.

**Demonstrates:** option pricing, Greeks, sensitivity analysis, Python implementation of financial models and basic model validation through put-call parity.

### `delta_hedging.py`

Monte Carlo delta-hedging simulator using Geometric Brownian Motion, daily hedge rebalancing and a self-financing cash account.

The model compares implied and realised volatility and analyses mean and standard deviation of terminal hedging P&L.

**Demonstrates:** Monte Carlo simulation, stochastic processes, dynamic hedging, realised vs implied volatility, derivatives P&L analysis and quantitative model testing.
